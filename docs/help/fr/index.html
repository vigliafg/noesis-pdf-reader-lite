Noesis PDF Reader Lite — Aide

Bienvenue dans l'aide complète. Vous trouverez ici la description de toutes les fonctionnalités, les instructions d'installation et de désinstallation pour chaque plateforme, ainsi que les informations sur l'usage licite du programme.

Fonctionnalités

Noesis PDF Reader Lite est un lecteur PDF doté d'un moteur d'extraction de texte adaptatif qui reconstruit automatiquement l'ordre de lecture de la page. Par rapport au projet parent, cette version utilise un seul moteur de rendu (PyMuPDF) et un seul moteur d'extraction (PyMuPDF4LLM), sans sélecteur à l'exécution : tout est automatique, avec la possibilité d'intervenir manuellement si nécessaire.

📄 Extraction intelligente

Le texte de la page est extrait en Markdown avec le bon ordre de lecture : colonnes, tableaux, titres, légendes.

🔍 Vue côte à côte

Page rendue à gauche, texte extrait à droite, avec navigation, table des matières (TOC) et zoom.

🚫 Zones d'exclusion

Faites glisser une boîte rouge sur le bruit (en-têtes, pieds de page, images, légendes) pour le retirer du texte.

🟩 Zones d'inclusion

Les boîtes vertes numérotées définissent l'ordre de lecture manuel des pages complexes.

🖼️ Extraction d'images

Sélectionnez une zone de la page et enregistrez la figure recadrée dans la galerie.

🌐 Traduction

Traduisez la page dans la langue cible choisie, avec un cache sur disque.

⚙️ Paramètres

Langue de l'interface, langues de traduction, zoom, police, en-tête et comportement de lecture.

🌍 Interface multilingue

Italiano, English, Français, Deutsch, Español — modifiable à la volée.

En résumé

  • Automatique par défaut : le moteur adaptatif décide du plan de lecture pour chaque page.
  • Manuel quand il le faut : les zones rouges et vertes n'interviennent que si vous les dessinez.
  • Zéro configuration pour commencer : ouvrez un PDF et lisez.

Pour commencer

  1. Lancez l'application (voir Installation pour votre plateforme).
  2. Cliquez sur 📂 Ouvrir un PDF dans la barre d'outils et choisissez un fichier PDF.
  3. La page apparaît à gauche, le texte extrait à droite.
  4. Utilisez ◀ Préc. / Suiv. ▶, les flèches ou l'index 📑 Sommaire pour vous déplacer dans le document.
  5. Si le texte contient du bruit, essayez les zones d'exclusion.
Conseil Au premier lancement, l'app s'ouvre à la dernière page du document (si l'option « Reprendre à la dernière page » est active) et dans la langue détectée du système d'exploitation.

Panneau droit (texte)

Trois onglets en haut à droite :

  • 📄 Original — le texte extrait (auto ou manuel).
  • 🇫🇷 … (drapeau + langue) — la traduction de la page dans la langue cible choisie dans les Paramètres.
  • 🖼️ Images — la galerie des figures extraites.

Barre d'état

En bas, elle affiche la page courante, le document et le temps d'extraction, ainsi que les messages liés aux zones.

Navigation

  • Boutons : ◀ Préc. / Suiv. ▶ et la case du numéro de page.
  • Clavier : flèches ← → et PgPréc/PgSuiv.
  • Table des matières (TOC) : cliquez sur 📑 Sommaire et choisissez une entrée pour sauter au chapitre.
  • Zoom : boutons 🔍−/🔍+, Ctrl++ / Ctrl+−, Ctrl+0 pour réinitialiser.
  • Reprise : si activé dans les Paramètres, l'app rouvre le document à la dernière page lue.

Extraction du texte

Le texte est extrait avec PyMuPDF4LLM puis réordonné par le moteur adaptatif, qui choisit automatiquement le plan de lecture (profil → plan → pipeline) : réordonnancement des colonnes, reconnaissance des tableaux, gestion des boîtes, légendes et didascalies, dé-duplication des titres et des espaces.

En-tête d'extraction

S'il est activé (Paramètres → « Afficher l'en-tête d'extraction »), une ligne informative apparaît au-dessus du texte :

── Backend : PyMuPDF4LLM ⚡ │ 210 ms │ 12 345 caractères │ Correctifs : Moteur adaptatif ──

Rendu Markdown

Le texte est affiché en Markdown rendu (tableaux et mise en forme inclus). Avec 📝 MD ✓ vous pouvez passer au texte brut. Raccourci : Ctrl+M.

Remarque L'extraction travaille sur le texte de la page. Les images contenant du texte peuvent générer du bruit : utilisez les zones d'exclusion pour les retirer.

Zones d'exclusion (rouges)

Lorsqu'une page contient des éléments qui ne font pas partie de la lecture (en-têtes, pieds de page, numéros de page, images avec texte, légendes, publicités), vous pouvez les exclure manuellement :

  1. Cliquez sur 🚫 Exclure une zone.
  2. Faites glisser une boîte rouge avec la souris sur le contenu à retirer.
  3. Le texte est recalculé immédiatement sans ce contenu.
  4. Appuyez à nouveau sur le bouton pour terminer.

Exclure + extraire en un seul geste

Si la zone rouge contient une image incorporée, elle est aussi extraite automatiquement dans l'onglet 🖼️ Images. La barre d'état confirme l'opération.

Attention L'exclusion est par-page et vit uniquement en mémoire : la fermeture de l'app fait perdre les zones.

Zones d'inclusion (vertes)

Pour les pages à mise en page complexe (par exemple plusieurs colonnes ou des boîtes dispersées), vous pouvez définir vous-même l'ordre de lecture avec les boîtes vertes numérotées :

  1. Cliquez sur 🟩 Inclure une zone.
  2. Faites glisser une boîte verte sur la première colonne/région de lecture (le numéro 1 apparaît).
  3. Dessinez la boîte suivante dans l'ordre de lecture (2, 3, …).
  4. Le texte est reconstruit selon la numérotation.

Règles

  • Une boîte verte = une colonne/région. N'utilisez pas une seule boîte pour couvrir deux colonnes.
  • Liste blanche : avec au moins une boîte verte, tout ce qui est hors des boîtes est écarté.
  • Dans une boîte : ordre de haut en bas, puis de gauche à droite.
  • Composition : les zones rouges retirent d'abord le bruit, les vertes ordonnent le reste ; en cas de chevauchement, le rouge gagne.

Extraction d'images

Vous pouvez recadrer une figure directement depuis la page :

  1. Cliquez sur 🖱️ Sélectionner une zone.
  2. Faites glisser un rectangle sur la figure.
  3. L'image est enregistrée dans l'onglet 🖼️ Images.

Dans la galerie, chaque image dispose des boutons :

  • 💾 Enregistrer — enregistre dans un fichier (PNG/JPEG).
  • 📋 Copier — copie dans le presse-papiers.
  • 🗑️ Supprimer — supprime de la galerie.
  • Clic sur l'aperçu pour agrandir.

Les images extraites sont stockées dans le dossier de données de l'app et sont conservées entre les lancements.

Traduction

Le panneau droit peut afficher la page traduite dans la langue cible choisie (par défaut : italien).

  1. Ouvrez ⚙️ Paramètres → section Langue.
  2. Choisissez la langue du document (source ; « auto » pour la détection automatique) et la langue de traduction (cible).
  3. Cliquez sur l'onglet avec drapeau + nom de la langue cible dans le panneau droit.

Comment ça marche

  • La traduction s'exécute en arrière-plan (Google Translate, sans clé).
  • Le cache sur disque évite de retraduire la même page : il est indexé par page et langue cible.
  • Pendant le dessin des zones, la traduction est différée d'une pause de 600 ms (pas de rafale de requêtes).
  • Si vous changez la langue cible, l'onglet se met à jour et la page est retraduite.
Attention La traduction nécessite une connexion Internet et envoie le texte de la page à un service externe. Ne traduisez pas de documents confidentiels sans en avoir le droit.

Paramètres

Le menu ⚙️ Paramètres (en haut à droite) regroupe tout ce qui concerne la langue et les préférences. Il est affiché dans la langue d'interface choisie et l'aperçu de la langue est en direct.

Langue

  • Langue de l'interface — it/en/fr/de/es ; elle change immédiatement toute l'interface (le texte du PDF reste dans la langue d'origine).
  • Langue du document (source) — la langue du PDF ; « auto » pour la détection automatique.
  • Langue de traduction (cible) — la langue dans laquelle traduire le texte.

Texte

  • Taille de police — 10–16 pt.
  • Rendu Markdown — activé/désactivé.
  • Afficher l'en-tête d'extraction — activé/désactivé.

Affichage

  • Zoom initial — 0,5×–4,0×.

Comportement

  • Reprendre à la dernière page — par document.
  • Mémoriser le dernier onglet — du panneau droit.

Tout est enregistré dans le fichier config.json du dossier de données de l'app (créé au premier lancement avec la langue de l'OS ou l'italien) et survit aux mises à jour. Voir Désinstallation pour l'emplacement exact par plateforme.

Installation

Le programme est portable : il n'existe pas de vrai installateur. Vous téléchargez le paquet de votre plateforme depuis la page des versions du projet sur GitHub et vous l'exécutez.

Windows (x64)

  1. Téléchargez NoesisPDFReaderLite-windows-x64.exe.
  2. Double-cliquez sur le fichier pour lancer l'app (il peut rester dans le dossier Téléchargements).
  3. Pas d'installation, pas de service, pas d'entrée de registre obligatoire.

Configuration requise : Windows 10/11 x64. SmartScreen peut demander une confirmation au premier lancement.

macOS (x64 / Apple Silicon)

  1. Téléchargez NoesisPDFReaderLite-macos-x64.dmg (Mac Intel) ou NoesisPDFReaderLite-macos-arm64.dmg (Apple Silicon).
  2. Ouvrez le .dmg et faites glisser l'app dans le dossier Applications.
  3. Au premier lancement, l'app n'est pas signée : clic droit sur l'app → Ouvrir et confirmez pour contourner Gatekeeper.

Configuration requise : macOS 11 ou ultérieur.

Linux (x86_64)

  1. Téléchargez NoesisPDFReaderLite-x86_64.AppImage.
  2. Rendez-le exécutable : 
    chmod +x NoesisPDFReaderLite-x86_64.AppImage
  3. Lancez-le en double-cliquant ou depuis le terminal : 
    ./NoesisPDFReaderLite-x86_64.AppImage

Configuration requise : Linux x86_64 avec FUSE (pour l'AppImage) et les bibliothèques Qt6. Si FUSE n'est pas disponible, extrayez l'AppImage avec --appimage-extract-and-run.

Depuis la source (développeurs)

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
Remarque Chaque mise à jour s'applique en téléchargeant et en exécutant le nouveau paquet de la même plateforme. Les préférences (config.json, cache, images) restent dans le dossier de données de l'app et ne sont pas touchées.

Désinstallation

Étant portable, la désinstallation consiste à supprimer les fichiers du programme et, si vous le souhaitez, le dossier de données utilisateur.

Windows

  1. Supprimez NoesisPDFReaderLite-windows-x64.exe.
  2. Pour supprimer aussi les données utilisateur, supprimez le dossier %APPDATA%\noesis-pdf-reader-lite\ (config, cache de traduction, images).

macOS

  1. Faites glisser l'app du dossier Applications vers la Corbeille.
  2. Pour supprimer aussi les données utilisateur, supprimez le dossier ~/Library/Application Support/noesis-pdf-reader-lite/.

Linux

  1. Supprimez le fichier NoesisPDFReaderLite-x86_64.AppImage.
  2. Pour supprimer aussi les données utilisateur, supprimez le dossier ~/.local/share/noesis-pdf-reader-lite/.
Attention Le dossier de données contient vos préférences et vos images extraites : sa suppression est irréversible. Si vous prévoyez de réinstaller, vous pouvez le conserver.

FAQ

Pourquoi le texte extrait contient-il des mots que je ne vois pas dans la page ?

Ce sont probablement des textes dans les images (figures, schémas), passés par l'OCR. Utilisez une zone d'exclusion sur la boîte de l'image pour les retirer.

L'ordre de lecture est incorrect sur une page complexe.

Utilisez les zones d'inclusion vertes pour définir manuellement l'ordre des colonnes.

Mes zones disparaissent quand je ferme l'app.

Oui : les zones (rouges et vertes) vivent en mémoire et sont par-page. Les préférences, en revanche, sont enregistrées dans le config.

Comment changer la langue de l'interface ?

⚙️ Paramètres → Langue → Langue de l'interface.

La traduction ne démarre pas.

Vérifiez la connexion Internet et que l'onglet de la langue cible est actif. La traduction est différée pendant le dessin des zones.

Une nouvelle version est-elle disponible ?

Les versions sont publiées sur la page GitHub du projet : téléchargez le paquet de votre plateforme et exécutez-le. Les préférences restent intactes.
