Noesis PDF Reader Lite — Help

Welcome to the complete help. Here you will find a description of all the features, installation and uninstallation instructions for every platform, and information about the lawful use of the program.

Features

Noesis PDF Reader Lite is a PDF reader with an adaptive text extraction engine that automatically rebuilds the reading order of the page. Compared to the parent project, this version uses a single rendering engine (PyMuPDF) and a single extraction engine (PyMuPDF4LLM), with no runtime chooser: everything is automatic, with the ability to intervene manually where needed.

📄 Smart extraction

The page text is extracted as Markdown with the correct reading order: columns, tables, headings, captions.

🔍 Side-by-side view

Rendered page on the left, extracted text on the right, with navigation, table of contents (TOC) and a built-in reader.

🚫 Exclusion zones

Drag a red box over noise (headers, footers, images, captions) to remove it from the text.

🟩 Inclusion zones

Numbered green boxes define the manual reading order for complex pages.

🗂️ Objects

Capture a page region (image, table or text) and find it in the collection, with actions per type.

🌐 Translation

Translate the page into the chosen target language, with an on-disk cache.

⚙️ Settings

Interface language, translation languages, theme, font, header and reading behavior.

💾 Batch export

Export several extracted/translated pages as a single Markdown, ZIP or folder.

✓ Next action

A floating button on the text area: translate the page, then translate the next one.

🎨 Theme

Dark, light or follow the system, applied live.

🌍 Multilingual UI

Italiano, English, Français, Deutsch, Español — switchable on the fly.

In short

  • Automatic by default: the adaptive engine decides the reading plan for every page.
  • Manual when needed: red and green zones only intervene when you draw them.
  • Zero configuration to start: open a PDF and read.

Getting started

  1. Launch the application (see Installation for your platform).
  2. Click 📂 Open PDF in the toolbar and choose a PDF file.
  3. The page appears on the left, the extracted text on the right.
  4. Use ◀ Prev. / Next ▶, the arrow keys or the 📑 Index to move through the document.
  5. If the text contains noise, try the exclusion zones.
Tip On first launch the app opens at the document's last page (if "Resume at last page" is enabled) and in the language detected from the operating system.

Right panel (text)

Three tabs at the top right:

  • 📄 Original — the extracted text (auto or manual).
  • 🇫🇷 … (flag + language) — the translation of the page into the target language chosen in Settings.
  • 🗂️ Objects — the collection of captured images, tables and texts.

The two text tabs (📄 Original and the translation) are editable windows: you can type, select, copy and paste freely (Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+Z). Each window has its own mini toolbar: A− / A+ / ↺ for the text size, 📋 to copy, 💾 to export the window text as .md or .txt (your edits included, the header excluded) and 🔁 to re-extract the page (Original tab) or re-translate it (language tab). While saving is enabled, an orange ● dot next to the buttons warns of edits not yet written to disk. The two windows zoom independently. Once you edit a text, it is shown as plain text. The changes are saved per page, in the app's data folder, and come back when you reopen the document.

Status bar

At the bottom it shows the current page, the document and the extraction time, plus the zone-related messages.

Navigation

  • Buttons: ◀ Prev. / Next ▶ and the page number box.
  • Keyboard: ← → arrows and PageUp/PageDown.
  • Table of contents (TOC): click 📑 Index and pick an entry to jump to the chapter.
  • Left pane: always fitted to the window (no zoom). The reading zoom lives in the reader.
  • Resume: if enabled in Settings, the app reopens the document at the last page read.

Text extraction

The text is extracted with PyMuPDF4LLM and then reordered by the adaptive engine, which automatically chooses the reading plan (profile → plan → pipeline): column reordering, table recognition, handling of boxes, legends and captions, de-duplication of headings and spacing.

Scanned PDFs Pages without a text layer are recognized via the Tesseract OCR included in the app (Windows/macOS/Linux packages); the OCR language follows the document-language setting (automatic detection by default). Extraction runs in the background, so the interface stays responsive, and results are cached per page.

Extraction header

If enabled (Settings → "Show extraction header"), an informational line appears above the text:

── Backend: PyMuPDF4LLM ⚡ │ 210 ms │ 12,345 characters │ Fix: Adaptive engine │ OCR: 🌐 Auto │ Transl: Google Translate ──

The engine name in the header always reflects the currently active engine — switching engines live updates it above both the original and the translated text.

Markdown rendering

The text is shown as rendered Markdown (tables and formatting included). With 📝 MD ✓ you can switch to plain text. Shortcut: Ctrl+M.

Note Extraction works on the text of the page. Images containing text inside them can generate noise: use the exclusion zones to remove them.

Exclusion zones (red)

When a page contains elements that are not part of the reading (headers, footers, page numbers, images with text, captions, ads), you can exclude them manually:

  1. Open the 🎯 Zones ▾ menu and choose 🚫 Exclude region.
  2. Drag a red box with the mouse over the content to remove.
  3. The text is recalculated immediately without that content.
  4. Choose 🚫 Exclude region again in the menu to finish.

Exclude + extract in one gesture

If the red zone contains an embedded image, the whole selected zone is captured automatically into the 🗂️ Objects tab (composite figures — several images, image + caption — are kept in full, not just one fragment; the focus stays on the Originale text window). The status bar confirms the operation.

Caution Exclusion is per-page and lives only in memory: closing the app loses the zones.

When you have finished drawing the zones, press ▶ Extract: the app ends editing, clears the page cache and re-runs it according to the selected zones.

Inclusion zones (green)

For pages with a complex layout (e.g. multiple columns or scattered boxes) you can define the reading order yourself with the numbered green boxes:

  1. Open the 🎯 Zones ▾ menu and choose 🟩 Include region.
  2. Drag a green box over the first reading column/region (the number 1 appears).
  3. Draw the next box in reading order (2, 3, …).
  4. The text is rebuilt following the numbering.

Rules

  • One green box = one column/region. Do not use a single box to span two columns.
  • Whitelist: with at least one green box, everything outside the boxes is discarded.
  • Inside a box: top-to-bottom order, then left-to-right.
  • Composition: the red zones remove noise first, the green zones order what remains; where they overlap, red wins.

Capturing objects

From the 📸 Capture ▾ menu you have two actions:

  • 📸 Capture image — saves the region as an image.
  • 🔤 Capture and interpret — saves the image and extracts its text: if the region has native text it reads it directly, otherwise it uses OCR; native tables become markdown.
  1. Choose the action from the 📸 Capture ▾ menu.
  2. Drag a rectangle over the image, the table or the object.

If the page already has zones, the capture warns you: reset them with 🧹 Reset zones first, then capture.

The 🗂️ Objects collection

Everything you capture lands in the 🗂️ Objects tab, grouped by type: Images, Tables and Texts. At the top of the tab you find the type filters, the count, 💾 Export all (to a folder: images as PNG, texts as .md) and 🗑️ Remove all.

Each object has the actions of its type:

  • Image — 💾 Save, 📋 Copy, 🗑️ Remove; click the thumbnail to enlarge.
  • Table — 📋 Copy markdown, 💾 Save .md, 🗑️ Remove.
  • Text — 📋 Copy text, 💾 Save .md, 🗑️ Remove.

Automatically extracted figures and manual captures live together in the same collection.

Translation

The right panel can show the page translated into the chosen target language (default: Italian).

  1. Open ⚙️ Settings → Language section.
  2. Choose the document language (source; "auto" for automatic detection) and the translation language (target).
  3. Click the tab with flag + name of the target language in the right panel.

How it works

  • The translation runs in the background using the engine chosen in ⚙️ Settings — Google Translate (default) or Microsoft Edge, both free and without an API key. You can also switch engine live with the Google / Microsoft radio buttons at the left of the translation tab bar: the choice is saved, the current page is re-translated and a toast confirms the change for 2 seconds.
  • While a translation is being produced, a toast (⏳ Translating with engine…) floats over the translated text; it disappears when the result appears.
  • The on-disk cache avoids re-translating the same page: it is indexed by page and target language.
  • While drawing zones the translation is deferred by a 600 ms pause (no request bursts).
  • If you change the target language, the tab updates and the page is re-translated.
Caution Translation requires an Internet connection and sends the page text to an external service. Do not translate confidential documents unless you have the right to.

Batch export

The 💾 Export button (or Ctrl+E) opens a five-step wizard to export a group of extracted and/or translated pages.

  1. Pages — current page, range, or a free list (e.g. 1,3,7-9; all for every page).
  2. Content — Original, Translation or Both; option Include figures.
  3. Languages and engine — source, target and engine; Translate missing pages first.
  4. Output — a single Markdown, single pages in a ZIP, or single pages in a folder; folder and file name.
  5. Summary — review and start.

A progress window shows the page being processed (with an animated preview), statistics and lets you cancel. When it finishes you can open the folder or copy the file to Downloads. Processed pages also fill the app's caches, so they are available immediately. The export honors saved edits and skips pages with manual zones (it runs in automatic mode).

Next action (FAB)

When processing finishes, a floating button appears at the bottom right of the text area (with an animated sheen and a notification dot). It is a single action, the "next step":

  • Original tab — 🌐 Translate page: goes to the page's translation.
  • Translation tab — ▶ Translate the next: goes to the next page and translates it.

The other local actions (copy, export, re-extract/re-translate) are in the mini toolbar above the text; the batch export is in the 💾 Export button at the top.

Built-in reader

From the 👁 Reader ▾ menu open a non-modal, read-only reader (or the system viewer). The reader has basic commands: navigation, zoom, fit-width/page, rotate and open externally. It opens on the current page and uses a separate document, so it never interferes with the main panel.

Theme

In ⚙️ Settings → Appearance choose the Dark, Light or Follow the system theme. The change is immediate and remembered. Animations (overlay during extraction/translation, sheen on the actions button, export preview) follow the active theme.

Settings

The ⚙️ Settings menu (top right) collects everything about language and preferences. It is shown in the chosen interface language and the language preview is live.

Language

  • Interface language — it/en/fr/de/es; it changes the whole UI immediately (the PDF text stays in the original language).
  • Document language (source) — the PDF language; "auto" for automatic detection.
  • Translation language (target) — the language to translate the text into.

Translation

  • Translation engine — Google Translate (default) or Microsoft Edge (free); no API key required. Changing it re-translates the current page. Google Translate automatically falls back between three free endpoints (dict-chrome-ex → translate-pa → gtx): if the service is blocked on your network, a warning appears instead of silently showing untranslated text.

Text

  • Font size — 10–16 pt.
  • Markdown rendering — on/off.
  • Show extraction header — on/off.
  • Save text edits — persist the edits made in the Original/Translated windows per document (on by default).
  • 🗑️ Clear saved edits — wipe the current document's saved edits (with confirmation).

View

  • Render quality — base render resolution, 0.5×–4.0× (affects sharpness).

Appearance

  • Theme — Dark, Light or Follow the system. Applies immediately and is remembered.

Advanced

  • Clear document cache — removes the current document's cache (extraction + translations), with confirmation.
  • Cache info — diagnostics panel with cache paths and page state.

Notifications

  • Notify when an export finishes — message and beep at the end of a batch export.

Behavior

  • Resume at last page — per document.
  • Remember last tab — of the right panel.

Everything is saved in the config.json file in the app data folder (created on first launch with the OS language or Italian) and survives updates. See Uninstallation for the exact location per platform.

Installation

The program is portable: there is no real installer. You download the package for your platform from the project release page on GitHub and run it.

Windows (x64)

  1. Download NoesisPDFReaderLite-windows-x64.exe.
  2. Double-click the file to launch the app (it can stay in the Downloads folder).
  3. No installation, no service, no mandatory registry entry.

Requirements: Windows 10/11 x64. SmartScreen may ask for confirmation on first launch.

macOS (x64 / Apple Silicon)

  1. Download NoesisPDFReaderLite-macos-x64.dmg (Intel Mac) or NoesisPDFReaderLite-macos-arm64.dmg (Apple Silicon).
  2. Open the .dmg and drag the app into the Applications folder.
  3. On first launch the app is not signed: right-click the app → Open and confirm to bypass Gatekeeper.

Requirements: macOS 11 or later.

Linux (x86_64)

  1. Download NoesisPDFReaderLite-x86_64.AppImage.
  2. Make it executable: 
    chmod +x NoesisPDFReaderLite-x86_64.AppImage
  3. Run it by double-click or from the terminal: 
    ./NoesisPDFReaderLite-x86_64.AppImage

Requirements: Linux x86_64 with FUSE (for the AppImage) and the Qt6 libraries. If FUSE is not available, extract the AppImage with --appimage-extract-and-run.

From source (developers)

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
Note Every update is applied by downloading and running the new package for the same platform. Preferences (config.json, cache, images) stay in the app data folder and are not touched.

Uninstallation

Being portable, uninstalling means removing the program files and, if you wish, the user data folder.

Windows

  1. Delete NoesisPDFReaderLite-windows-x64.exe.
  2. To also remove user data, delete the folder %APPDATA%\noesis-pdf-reader-lite\ (config, translation cache, images).

macOS

  1. Drag the app from the Applications folder to the Trash.
  2. To also remove user data, delete the folder ~/Library/Application Support/noesis-pdf-reader-lite/.

Linux

  1. Delete the NoesisPDFReaderLite-x86_64.AppImage file.
  2. To also remove user data, delete the folder ~/.local/share/noesis-pdf-reader-lite/.
Caution The data folder contains your preferences and extracted images: deleting it is irreversible. If you plan to reinstall, you can keep it.

FAQ

Why does the extracted text contain words I do not see in the page?

They are probably text inside images (figures, diagrams), passed through OCR. Use an exclusion zone on the image box to remove them.

The reading order is wrong on a complex page.

Use the green inclusion zones to define the column order manually.

My zones disappear when I close the app.

Yes: the zones (red and green) live in memory and are per-page. Preferences, on the other hand, are saved in the config.

How do I change the interface language?

⚙️ Settings → Language → Interface language.

Translation does not start.

Check the Internet connection and that the target-language tab is active. Translation is deferred while drawing zones.

Is a new version available?

Releases are published on the project GitHub page: download the package for your platform and run it. Preferences stay intact.
